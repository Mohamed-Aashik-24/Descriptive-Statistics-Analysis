# 📊 Descriptive Statistics Analysis

A data analysis project that explores **Descriptive Statistics** using the *World Happiness Report 2017* dataset.  
This project focuses on summarizing, visualizing, and interpreting data to extract meaningful insights about global happiness factors.

---

# 📁 Repository Structure

```
Descriptive-Statistics-Analysis/
│
├── Happiness_2017_Analysis.ipynb   # Jupyter Notebook with full analysis
├── happiness_2017.csv              # Dataset used for analysis
└── README.md                      # Project documentation
```

---

## 🎯 Objective

The main goal of this project is to:

- Understand descriptive statistics concepts  
- Perform statistical analysis on real-world data  
- Visualize distributions and relationships  
- Interpret factors affecting happiness scores  

---

## 🧠 Concepts Covered

This project demonstrates:

- Mean, Median, Mode  
- Standard Deviation  
- Variance  
- Minimum & Maximum  
- Quartiles & IQR  
- Correlation  
- Data Distribution  
- Summary Statistics  

---

## 🛠️ Tech Stack

- **Python**  
- **Jupyter Notebook**  
- **Pandas** – Data manipulation  
- **NumPy** – Numerical operations  
- **Matplotlib** – Data visualization  
- **Seaborn** – Statistical plots  

---

## 📊 Dataset Information

**Dataset:** World Happiness Report 2017  

Contains factors such as:

- Country  
- Happiness Score  
- Economy (GDP per capita)  
- Family  
- Health  
- Freedom  
- Generosity  
- Trust (Government Corruption)

## 🚀 How to Run the Project

### 1️⃣ Clone the repository

```
git clone https://github.com/Mohamed-Aashik-24/Descriptive-Statistics-Analysis.git
```

2️⃣ Navigate to the folder
```
cd Descriptive-Statistics-Analysis
```

3️⃣ Install required libraries
```
pip install pandas numpy matplotlib seaborn notebook
```

4️⃣ Run Jupyter Notebook
```
jupyter notebook
```

5️⃣ Open the notebook
```
Happiness_2017_Analysis.ipynb
```

## 📈 Analysis Performed

- Data cleaning & preprocessing  
- Statistical summary generation  
- Distribution plots  
- Correlation heatmaps  
- Comparative country analysis

---

## 📌 Key Insights

- Economic strength strongly influences happiness  
- Social support (family) highly correlates with happiness score  
- Health and freedom contribute significantly  
- Trust and generosity show moderate impact
